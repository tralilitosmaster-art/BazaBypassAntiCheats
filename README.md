# BBAC

**BazaBypassAntiCheat** — фреймворк обхода клиентских античитов в Roblox.
Версия: `V0.1.0` · API аддонов: `1` · Статус: scaffold

---

## Что это

BBAC — это UI-оболочка и набор методов для нейтрализации самописных античитов
в плейсах Roblox. Фреймворк не привязан к конкретному античиту: он ищет
подозрительные скрипты и remote-события по эвристикам, а точные имена
подставляются под конкретный плейс через конфиг.

Работает в executor-окружении с доступом к `getrawmetatable`, `hookmetamethod`,
`getconnections`, `loadstring`, `request`.

---

## Возможности

- Премиальный чёрный UI: три вкладки, перетаскиваемое окно, моноширинные данные.
- Шесть методов обхода, разбитых на две категории.
- Песочница аддонов с белым списком API.
- Загрузка аддонов из указанного пользователем источника.
- Лог действий с временными метками.

## Вкладки

### Home

Профиль: ник, аватар, UserId, статус bypass. Ниже — список загруженных
функций с их текущим состоянием (`on` / `off`).

### AC

Две категории методов.

**humanoid** — движение и коллизии:

| Метод | Назначение |
|---|---|
| Velocity Phantom | Desync позиции: сервер видит легальную траекторию |
| Property Spoof | Спуф `WalkSpeed` / `JumpPower` для детекторов |
| Noclip | Отключение коллизий персонажа |
| Fly | Вертикальное движение без гравитации |

**alt** — обход серверной авторитетности:

| Метод | Назначение |
|---|---|
| Script Purge | Удаление локального античита + реинжект на `CharacterAdded` |
| Remote Blackhole | Блок отчётов через `FireServer` / `InvokeServer` |
| Connection Sever | `Disable()` соединений античита через `getconnections` |
| Function Hook | Замена `Detect` / `Flag` / `Report` / `Kick` на пустые функции |

### Addons

Загрузчик пользовательских аддонов. Поле ввода исходника, кнопка `LOAD ADDON`,
лог загрузки. Аддоны исполняются в песочнице с доступом только к `BBAC.*`.

## Методы обхода — детали

### Script Purge

Ищет `LocalScript` / `ModuleScript` по ключевым словам (`AntiCheat`, `BBAC`,
`Detector`, `Guard`, `Report`, `Flag`) в `PlayerGui`, `Player`, `Character`.
Удаляет найденное, вешает слушатель `CharacterAdded` для повторной зачистки
после респавна.

### Remote Blackhole

Хук `__namecall` на `FireServer` / `InvokeServer`. Если имя remote содержит
ключевое слово из списка — вызов глушится, возвращается `nil`. Античит думает,
что отчёт ушёл.

### Property Spoof

Хук `__index` на `Humanoid`. Когда читает античит — возвращаются оригинальные
значения. Когда читает твой скрипт — реальные. Разделение по `debug.info`
или `getcallingscript`.

### Connection Sever

Через `getconnections` достаются соединения, навешанные античитом на события.
Каждое переводится в `:Disable()`. Работает, когда скрипт не удалён, но его
функции уже на событиях.

### Function Hook

Функции с известными именами (`Detect`, `Flag`, `Report`, `Kick`) заменяются
на `newcclosure(function() end)`. Античит вызывает — ничего не происходит.

### Velocity Phantom

Подмена пакета позиции в репликаторе. Сервер видит легальную траекторию,
реальный персонаж движется как хочет. Работает против клиентских проверок
скорости и позиции. **Не работает** против серверных raycast-проверок ноклипа —
для них нужна отдельная дыра в античите.

Связка для максимального покрытия: `Velocity Phantom + Property Spoof +
Remote Blackhole`.

## Быстрый старт

1. Открой плейс, зайди в консоль executor.
2. Найди точные имена `LocalScript` и `RemoteEvent`, которые создаёт античит.
3. Подставь их в `TARGET_NAMES` и `REMOTE_KEYWORDS` в конфиге.
4. Загрузи `BBAC_V010.lua` в executor.
5. Вкладка AC → включи нужные методы → `ACTIVATE`.

Если античит реинжектится после респавна — `Script Purge` уже вешает
слушатель, повторной активации не требуется.

## Аддоны

Аддоны — это пользовательские расширения BBAC. Пишутся на Lua, грузятся
в песочницу, получают доступ только к API `BBAC.*`. Аддон может добавить
метод, повесить обработчик на событие bypass, изменить конфиг.

### Формат

Один файл `.lua` с шапкой-манифестом в комментарии. Без шапки загрузчик
не принимает файл.

```lua
-- @name Velocity Helper
-- @author username
-- @version 1.0.0
-- @api 1
-- @desc расширяет Velocity Phantom: плавный спуф при телепорте
```

| Поле | Обязательно | Описание |
|---|---|---|
| `@name` | да | Отображаемое имя |
| `@author` | да | Автор |
| `@version` | да | Semver |
| `@api` | да | Версия API BBAC, под которую написан аддон |
| `@desc` | нет | Короткое описание |

`@hash` — контрольная сумма тела файла. Считается при сохранении аддона,
сверяется при загрузке. Несовпадение = аддон не грузится.

### API песочницы

Аддон видит только это:

```lua
BBAC.register(name, callback)  -- регистрация аддона
BBAC.log(msg)                  -- запись в лог BBAC
BBAC.toggle(method_id, on)     -- включить/выключить метод
BBAC.getState()                -- таблица состояния
BBAC.setConfig(key, value)     -- конфиг
BBAC.getCharacter()            -- персонаж (read-only)
```

Никакого `game`, `HttpGet`, `loadstring` в песочнице нет. Всё, что нужно
аддону от мира, он просит через `BBAC.*`.

### Загрузка

Аддоны грузятся из источника, который указывает пользователь: локальный файл,
raw-URL, буфер обмена. Загрузчик читает манифест, проверяет `@api`,
сверяет `@hash`, компилирует через `loadstring`, запускает в песочнице.

Аддон не имеет доступа к сети и к `game` — если ему нужно что-то из мира,
он получает это через API и только в том объёме, который API отдаёт.

## Ограничения

- Velocity Phantom не обходит серверные raycast-проверки ноклипа.
- Property Spoof требует различения вызовов античита и своего скрипта —
  не всегда возможно без `debug.info`.
- Аддон исполняется в песочнице, но `loadstring` в executor-окружении —
  это всегда доверие к коду. Чужие аддоны не грузятся без проверки манифеста
  и хеша.
